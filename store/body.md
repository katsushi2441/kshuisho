### 先に、この道具がしないことを書きます

**文章は作りません。** 質問主意書の下書きを生成する道具ではありません。過去の質問と答弁を並べ、答弁書の定型句を数え、質問主意書の型（前提の事実・過去の答弁の引用・問い）を空欄つきで示すところまでです。文章を書くのは人です。

**要約も論評もしません。** 出すのは、衆議院・参議院が公開している質問本文と答弁本文の機械的な抜粋と、原文へのリンクだけです。

**「答えていない型」は評価ではありません。** 答弁書に出てくる定型句（「お答えすることは困難である」「御質問の趣旨が必ずしも明らかではない」「承知していない」「検討してまいりたい」「仮定の御質問」「個別の事案」）を語の一致で数えたものです。

---

### 何ができるか

**論点の語を入れると、同じ論点の過去の質問・政府の答弁・答えていない型が1画面に並びます。**

1. **政府はこう答えている** … 答弁書の段落のうち検索語を含むものを、原文のまま新しい順に。要約しません
2. **答えていない型が返った質問** … 同じ聞き方をすると同じ型が返りやすい、という材料
3. **過去の質問主意書** … 件名・提出者・提出日・答弁書受領日・型のタグつき
4. **質問主意書の型** … 前提の事実／過去の答弁の引用／問い（「困難」とされた点は数字と期間を限定して聞き直す、「検討中」は主体と期限を聞く、「承知していない」は把握の予定を聞く）を空欄つきで

あわせて、次のページが最初から入っています。

- **質問主意書1件のページ** … 質問本文と答弁本文を左右に、提出日・内閣転送日・答弁書受領日・提出からの日数・答弁の項目数つき
- **提出者ごと**、**回次ごと**、**型ごと**の一覧
- **CSV と JSON API**、**sitemap.xml・llms.txt**

### なぜ要るのか

質問主意書は月に1,600回検索されている制度で、衆参のサイトに全文が公開されています。ただし件名の一覧しかなく、本文の中は検索できません。「この論点は過去に誰が聞いて、政府は何と答えたか」を調べるには、会期ごとの一覧を開いて1件ずつ本文を読むしかありません。

秘書の調査時間はここに消えます。そして同じ聞き方をすると、同じ「お答えすることは困難である」が返ってきます。

この道具は、本文の中までことばで引けるようにして、答弁の定型句を数えただけです。それだけで、次に何を聞くべきかが見えます。

### 置き方（3分）

1. `kshuisho.php` と `kshuisho_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（共有サーバーの既定がPHP5.6のことがあるため）
3. `https://あなたのドメイン/kshuisho.php/` を開く

**データベースサーバーも常駐プロセスもポートも要りません。** 必要なのはPHP 8とPDO SQLiteだけです。書き込み権限も不要です。**検索は置いた場所で完結し、外部のAIやAPIには何も送りません。** 事務所の中で、どの論点を調べているかが外に出ません。

### 更新のしかた

会期が進むと質問主意書と答弁書が増えます。同梱のPythonを3本動かせば、新しいデータベースができます。

```
python3 scripts/fetch_shugiin.py --from 212 --to 221
python3 scripts/fetch_sangiin.py --from 212 --to 221
python3 scripts/build_db.py
```

会期の範囲は引数で広げられます（古い回次も同じ形式で公開されています）。

### こんな方に

- **国会議員事務所** … 質問主意書を書く前に、同じ論点の過去の質問と答弁を5分で並べられます。答弁書の原文をそのまま引用できます
- **地方議員事務所** … 国が「検討中」「承知していない」と答えている論点は、地方議会で聞く材料になります
- **記者・研究者** … 「お答えすることは困難」がどの論点に集中しているかを、提出者別・回次別に数えられます
- **自治体のDX担当** … 国の公開ページを本文まで引ける形にする例として、そのまま流用できます
